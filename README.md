## 👨‍💻 About Me

I'm **Misagh Momeni**, a software developer who enjoys exploring the intersection of **backend engineering, web development, AI, data analytics, and infrastructure automation**.

My GitHub is a hands-on engineering portfolio: API services in **Go and Python**, **Django and PHP** web applications, an **OpenAI-compatible RAG API**, data analysis projects, **Ansible** provisioning, **Cisco pyATS** verification, command-line utilities, and experiments in **C++, Java, and SQL**.

I value readable code, automation, maintainable architecture, continuous learning, and turning ideas into working software.

- 🔭 **Building:** Backend services, developer tooling, automation workflows, and web applications.
- 🧠 **Exploring:** Retrieval-augmented generation, applied AI, data analysis, and system design.
- 🛠️ **Enjoy working with:** Python, Go, Django, PHP, JavaScript, Linux, and SQL.
- 📚 **Learning by building:** From algorithms and CLI tools to API integrations and full-stack projects.
- 🤝 **Open to:** Open-source collaboration, technical discussions, and interesting software projects.

> **Engineering mindset:** Understand the problem. Build a simple solution. Test it. Improve it.
